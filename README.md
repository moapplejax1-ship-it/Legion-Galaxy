# Legion Galaxy

An MMORTS empire-builder for iOS & Android (Unity), inspired by *Galaxy Empire*.

- Full game design: see [DESIGN.md](DESIGN.md)
- Source: `Unity/LegionGalaxy/` — Unity (C#/uGUI) scaffold with a Galaxy-Empire-style
  dark sci-fi HUD (procedurally generated planet sprites, glowing tech-frame panels)
  covering the Home Planet → Continents → Buildings → Solar System flow.
- Setup guide: [Unity/SETUP.md](Unity/SETUP.md) — how to wire the scripts into
  scenes/prefabs in the Unity Editor and build for both iOS and Android from one project.
