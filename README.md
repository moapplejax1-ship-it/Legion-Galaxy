# Legion Galaxy

An MMORTS empire-builder for iOS (SwiftUI), inspired by *Galaxy Empire*.

- Full game design: see [DESIGN.md](DESIGN.md)
- Source: `LegionGalaxy/` — SwiftUI app with a Galaxy-Empire-style dark sci-fi HUD
  (procedurally drawn planets, ships, glowing tech-frame panels) covering the
  Home Planet → Continents → Buildings → Solar System flow described in the design doc.

Open `LegionGalaxy/LegionGalaxy.xcodeproj` in Xcode (iOS 16+) to run.
